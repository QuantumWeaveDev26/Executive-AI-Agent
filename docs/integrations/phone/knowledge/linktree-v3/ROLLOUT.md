## Acceptance and diagnosis

| Scenario | Pass condition |
|---|---|
| Interrupt the services explanation with “Wait, do you build apps?” | Agent yields promptly, hears the complete question and answers about app development. It drops the abandoned answer. |
| Interrupt in Kannada or Kanglish, then pause briefly mid-question | Agent waits for the rest of the utterance, responds naturally in the chosen language and asks at most one follow-up. |
| Ask about Appu, film previsualization or InstaSkills | Agent uses the right offer and gives a concise grounded answer. It avoids unconfirmed details, prices and guarantees. |
| Outbound caller interrupts with a company question, then declines | Agent answers briefly and respects the refusal. It preserves the original approved purpose and performs zero additional external actions. |

Observe audio, not just text. If there is no interrupt event in available provider evidence, isolate speech detection or the phone audio path. Compare a browser Voice test with the phone path before tuning. If an interrupt event appears but speech continues, isolate playback cancellation in the provider path. If playback stops but Thaara replies too early, compare the end-of-turn timing. If it hears the full question but resumes the old answer, isolate the conversation policy. Change one setting at a time and preserve the rollback version. Thaara’s current Instant Outbound integration does not stream or clear Sarvam’s managed telephone audio.
